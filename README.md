# 🚀 Installation

Clone the repository

```bash
git clone https://github.com/DragAditya/portfolio.git
```

Move into the folder

```bash
cd portfolio
```

Install dependencies

```bash
npm install
```

Run locally

```bash
npm run dev
```

Open

```text
http://localhost:3000
```
